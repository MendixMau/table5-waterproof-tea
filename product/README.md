# product

## HTML demo (the one shown in the pitch)

Start: `open product/index.html` (one self-contained file that works offline and loads nothing at runtime). Then press **F** for full screen.

| Key | Does |
|---|---|
| Space | Pour boiling water; once the bag has sealed, Space brews again (2nd, 3rd infusion) |
| R | Reset |
| 1 / 2 / 4 | Time-lapse speed (default 1x: Sencha runs from pour to sealed in about 25 s) |
| F | Full screen |
| ← → | Change tea |

The demo tea is **Sencha**, selected on load. The bag opens when the water cools to 80 °C and seals again below 70 °C (facts.md). The ordinary 1908 bag sits beside it.

Rehearsal: `index.html#tea=sencha&sec=16` jumps to 16 demo seconds after the pour and pauses there. The tea ids are gyokuro, sencha, longjing, tieguanyin, puerh and eb.
