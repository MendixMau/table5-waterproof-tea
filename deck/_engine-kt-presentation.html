Mendix 위젯 vs. 고코드·바이브코드 앱
항목 Mendix 위젯 (.mpk) 별도 앱 / npm
인증 ✓ Mendix 세션 자동 OAuth / JWT 직접 구현
데이터 연동 ✓ 엔티티 직접 바인딩 REST API 레이어 필요
배포 ✓ 앱과 동일 파이프라인 별도 인프라 + 호스팅
다른 앱에 재사용 ✓ .mpk 내보내기 → 드래그앤드롭 npm + semver + 빌드 설정
유지보수 ✓ 1개 소스 → 전체 앱 자동 각 앱마다 버전 업그레이드
디자인 시스템 통합 ✓ Atlas 테마 자동 상속 커스텀 CSS 직접 작성
마켓플레이스 배포 ✓ 1클릭 마켓플레이스 해당 없음
"고코드로 만들면 인증·API·CI/CD만으로 1주일 이상. Mendix 위젯은 모두 내장. 그리고 다음 앱엔 .mpk 파일 하나면 된다."
